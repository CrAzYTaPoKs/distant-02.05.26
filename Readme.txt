Расписание ГАПОУ СКиПТ

Описание проекта

Веб-интерфейс для удобного просмотра расписания занятий.

Основные улучшения по сравнению с исходным расписанием:

1)современный интерфейс;
2) адаптивная вёрстка;
3)удобное отображение занятий;
4)фильтрация по группе, дате и типу занятия;
5)улучшенная читаемость на телефоне и ноутбуке.

Использованные технологии

1)HTML5
2)CSS3
3)Flexbox
4)Media Queries
Как запустить

1. Скачать проект
2. Открыть файл `index.html` в браузере

Почему выбран такой дизайн

Исходное расписание сложно воспринимается из-за:
1) перегруженности,
2) мелкого текста,
3) неудобной таблицы,
4) слабой адаптации под телефон.

В новой версии:
1)занятия разделены на карточки;
2) добавлены отступы и цветовые акценты;
3) информация читается быстрее;
4) интерфейс адаптирован под мобильные устройства.
